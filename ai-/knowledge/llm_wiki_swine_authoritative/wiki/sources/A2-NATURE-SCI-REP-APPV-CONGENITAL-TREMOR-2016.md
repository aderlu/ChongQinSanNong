# Atypical Porcine Pestivirus as a Possible Cause of Congenital Tremor Type A-II in Newborn Piglets

## Source

- URL: https://www.nature.com/articles/srep27735
- Publisher: Scientific Reports / Nature Portfolio
- Publication year: 2016
- Accessed: 2026-05-08

## Usable Boundary

- Use for APPV association with congenital tremor type A-II in newborn piglets and for caution that APPV conclusions should be made with compatible syndrome, age, tissue detection, and differential exclusion.
- Use for dataset generation where APPV is an uncommon pestivirus entity linked mainly to newborn tremor rather than generic swine fever.
