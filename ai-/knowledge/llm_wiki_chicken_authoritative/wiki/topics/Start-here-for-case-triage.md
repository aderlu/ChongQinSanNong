# Topic: Start here for case triage

## What this page is for

- Use this page first when a case arrives and you need the shortest authoritative path through the wiki.
- Disease pages: 60 | Drug summaries: 44 | Standards anchors: 34 | Rule pages: 30

## Recommended workflow

- 1. Read the likely disease page or the closest category bucket to establish the problem frame.
- 2. If the disease is reportable, official, or quarantine-sensitive, jump to the linked rule anchors before drafting any action.
- 3. If medication is mentioned, validate ingredient-level compliance in `wiki/drugs/` and trace the evidence to `wiki/sources/`.
- 4. If confidence is low or evidence is missing, stop at the source page and inspect the raw original before promoting any statement.

## Evidence guardrails

- Prefer pages with a primary local source and linked standards anchors.
- Treat topic pages as navigation only; authoritative claims must resolve to disease, drug, rule, or source pages.
- Open the unresolved evidence queue when the case touches missing evidence: [Issue Queue](../../issues/manual_fetch_queue.md).
