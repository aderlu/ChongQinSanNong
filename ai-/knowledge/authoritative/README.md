# 鸡病权威知识库

本目录存放已核验的原始证据文件、清单台账，以及基于真实落库资料整理出的鸡病知识资产。

如果你要把这些资料以 `llm-wiki` 方式查询、迁移或交给其他 Agent / 项目复用，请进入：

- [llm_wiki_chicken_authoritative](../llm_wiki_chicken_authoritative/README.md)

## 结构

- `raw/`：原始网页、PDF、公告、标准页、技术参考页
- `manifests/`：来源清单、证据登记、病种覆盖和索引文件
- `curated/`：人工可读的总结与疾病资料卡

## 覆盖说明

- 中国官方法规、公告和标准仍然是国内合规判断的最高权威。
- WOAH 技术文件用于补强国际疾病定义、实验室诊断和监测框架。
- Merck Veterinary Manual 用于补强常见鸡病的临床与管理场景覆盖。
- 本知识库追求“最大化真实、可核验覆盖”，但不会对公开渠道根本拿不到的全文标准或产品级标签数据作虚假完整承诺。
