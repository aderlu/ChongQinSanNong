# Knowledge Change Records

This directory stores change records and work-trace documents for the LLM wiki knowledge base.

Each modification should add one Markdown record here. A record should explain:

- What problem existed before the change.
- What the code, scripts, indexes, or knowledge files looked like before the change.
- What was changed, updated, added, or reorganized.
- What risk was reduced for generation, evaluation, retrieval, or production use.
- What verification was run and what still needs follow-up.

Suggested file name format:

`YYYY-MM-DD-short-topic.md`
