# 2026-05-14 Web Access 高价值疾病页补强记录

## 1. 本次目标

基于 `web-access` skill，针对当前 wiki 中高价值但证据偏薄的疾病页，使用权威一手来源网页补齐可核验事实，提升问诊分诊、差异诊断和边界控制能力。

## 2. 补强原则

1. 只使用权威来源网页和当前页面已有锚点支持的事实。
2. 只追加“可核验事实”和“问诊有价值的边界提示”，不重写整页结构。
3. 保留 partial page 的定位，不把缺口页硬改成 full clinical page。

## 3. 本次补强的页面

### DIS-010 猪δ冠状病毒感染

补入一手来源：Merck Veterinary Manual 的 coronaviral enteritis 页面。

新增事实重点：

- 该类冠状病毒肠炎可影响各年龄段猪只。
- 临床上 TGEV、PEDV、PDCV 难以仅凭症状区分。
- 传播可经感染猪只及污染器具/运输车辆间接传播。
- 小肠绒毛上皮受损可造成腹泻、脱水和代谢性酸中毒。
- 问诊上应优先做“病毒性胃肠炎分诊”和采样建议，而不是单病原直接确诊。

### DIS-045 猪钩端螺旋体病

补入一手来源：WOAH disease page / Terrestrial Manual，以及现有成套 web source。

新增事实重点：

- 猪钩端螺旋体病常以繁殖损失为主，地方性群体可症状不明显。
- 妊娠母猪和幼龄仔猪更可能出现临床感染。
- MAT 单次读数诊断价值有限，成对血清更有帮助。
- 适合繁殖障碍问诊、采样和差异诊断，不适合直接生成处置或治疗方案。

### DIS-053 猪结核病

本次仅做定位强化，未硬改为完整临床页。

新增事实重点：

- 更适合承接慢性消耗、结节性病变、人兽共患风险分诊。
- 现有标准元数据只支持“存在现行标准”，不支持直接外推采样 SOP 或阳性判定。

### DIS-069 玉米赤霉烯酮中毒

新增事实重点：

- 最有价值的问诊场景是后备母猪/母猪的外阴肿胀、乳腺肿大、返情或繁殖异常 + 饲料暴露史。
- 核心是雌激素样作用，应优先追问饲料来源、批次和霉变。
- 更适合繁殖障碍与饲料暴露鉴别，不适合输出药物治疗或单点确诊。
